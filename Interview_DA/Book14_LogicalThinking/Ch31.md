## Concept in plain language

### The problem induction solves

In Chapter 30 you learned that checking examples never proves a claim about *every* whole number. But there are infinitely many whole numbers, and you cannot check them all. How can one short argument cover them all?

**Mathematical induction** is a method for proving claims of the form "this is true for every whole number n, starting from some first value". (Do not confuse it with "inductive reasoning" from Chapter 1, which is guessing a general rule from examples. Mathematical induction is a full, certain proof.) In this book we cover **the idea only**: enough to read a proof and write a simple one.

### The domino picture

Line up an endless row of dominoes, numbered 1, 2, 3, and so on.

- **Fact A (the start):** Domino 1 is knocked over.
- **Fact B (the passing-along rule):** Whenever *any* domino falls, it knocks over the *next* one.

If both facts hold, then domino 1 falls, so domino 2 falls, so domino 3 falls, and so on forever. Every domino falls. You never had to check domino 5,000 separately.

The same picture works with a ladder: you can stand on the first rung (A), and if you can stand on any rung you can climb to the next (B). Then you can reach every rung.

### The two parts of an induction proof

| Part | Plain-language name | What you do |
|---|---|---|
| **Base case** | "The first domino falls" | Check the claim for the first value (usually n = 1) by plain calculation |
| **Inductive step** | "Each domino knocks over the next" | Assume the claim is true for some value k (this assumption is called the **inductive hypothesis**), then show it must be true for k + 1 |

Then you conclude: "By induction, the claim holds for every n from the start value on."

### The most important warning

**You need both parts.**

- Base case without the step: you know domino 1 falls, but nothing says it hits domino 2.
- Step without the base case: dominoes would knock each other over *if* any fell, but nobody pushed the first one. (Example 5 shows a claim where the step works perfectly and the claim is still false.)

Also: in the inductive step you may *assume* the claim for k. That is not cheating. The step only proves "if k works then k + 1 works"; the base case supplies the first working value.

### A word on "sum patterns"

Many induction examples add up a pattern, such as 1 + 2 + 3 + ... + n. The usual routine for the step is: write the sum up to k + 1 as "the sum up to k" plus "the last term", replace the first part using the assumption, and tidy up until it matches the formula with n = k + 1.

> **Why this matters for data work**
> Induction is the thinking behind anything that builds step by step: a running total, a month-by-month balance, a loop in code that adds one row at a time. When you can say "the start is right, and each step keeps it right", you can trust a long calculation without checking every line. It also trains you not to trust a pattern from a few cases alone.

## 5 solved examples

### Example 1: the sum of the first n whole numbers

**Claim:** 1 + 2 + 3 + ... + n = n(n + 1) / 2, for every n = 1, 2, 3, ...

**Step 1: base case (n = 1).** Left side: just 1. Right side: 1 × 2 / 2 = 1. They match. *Why:* this is the first domino falling.

**Step 2: assume it works for k.** Suppose 1 + 2 + ... + k = k(k + 1) / 2. *Why:* this is the inductive hypothesis: "domino k has fallen".

**Step 3: build the sum up to k + 1.** 1 + 2 + ... + k + (k + 1) = [k(k + 1) / 2] + (k + 1). *Why:* we replaced the first k terms using the assumption, and added the new last term.

**Step 4: tidy up.** [k(k + 1) / 2] + (k + 1) = (k + 1) × (k / 2 + 1) = (k + 1)(k + 2) / 2. *Why:* both parts contain (k + 1), so we pull it out; then k / 2 + 1 is (k + 2) / 2.

**Step 5: compare with the target.** The formula for n = k + 1 is (k + 1)((k + 1) + 1) / 2 = (k + 1)(k + 2) / 2. It matches. *Why:* this shows "domino k falling makes domino k + 1 fall".

**Conclusion:** By induction the formula holds for every n. Sanity check (not part of the proof): n = 5 gives 1 + 2 + 3 + 4 + 5 = 15 and 5 × 6 / 2 = 15.

### Example 2: the sum of the first n odd numbers

**Claim:** 1 + 3 + 5 + ... + (2n minus 1) = n², for every n = 1, 2, 3, ...

**Step 1: base case (n = 1).** Left: 1. Right: 1² = 1. Match. *Why:* first domino.

**Step 2: assume** 1 + 3 + ... + (2k minus 1) = k².

**Step 3: add the next odd number.** The next term after 2k minus 1 is 2(k + 1) minus 1 = 2k + 1. So the sum up to k + 1 is k² + (2k + 1). *Why:* use the assumption for the first part, then add the new term.

**Step 4: recognise the result.** k² + 2k + 1 = (k + 1)². *Why:* that is a well-known pattern: (k + 1) times (k + 1) expands to k² + 2k + 1.

**Step 5: match the target.** The claim for n = k + 1 says the sum equals (k + 1)². It does. 

**Conclusion:** True for every n. Check: 1, 1 + 3 = 4, 1 + 3 + 5 = 9, 1 + 3 + 5 + 7 = 16, 25, 36: the squares.

### Example 3: the sum of the first n even numbers

**Claim:** 2 + 4 + 6 + ... + 2n = n(n + 1), for every n = 1, 2, 3, ...

**Step 1: base case (n = 1).** Left: 2. Right: 1 × 2 = 2. Match.

**Step 2: assume** 2 + 4 + ... + 2k = k(k + 1).

**Step 3: add the next even number,** 2(k + 1). Sum up to k + 1 = k(k + 1) + 2(k + 1). *Why:* assumption for the first part, plus the new term.

**Step 4: pull out the common (k + 1).** k(k + 1) + 2(k + 1) = (k + 1)(k + 2). *Why:* (k + 1) appears in both parts.

**Step 5: match the target.** For n = k + 1 the formula gives (k + 1)((k + 1) + 1) = (k + 1)(k + 2). It matches.

**Conclusion:** True for every n. Check: n = 4 gives 2 + 4 + 6 + 8 = 20 and 4 × 5 = 20.

### Example 4: paying with 3-rupee and 5-rupee vouchers

**Claim:** Every amount of 8 rupees or more can be paid exactly using only 3-rupee and 5-rupee vouchers.

First, why start at 8? The amounts 1, 2, 4 and 7 cannot be paid this way, so the claim would be false from 1. The first amount where it works and keeps working is 8.

**Step 1: base case (8).** 8 = 3 + 5. *Why:* first domino.

**Step 2: assume** some amount n (with n at least 8) can be paid with 3s and 5s.

**Step 3: show n + 1 can be paid too.** There are two cases, because the payment for n either contains a 5-rupee voucher or it does not. *Why:* we need a plan for each possibility.
- **Case A: it uses at least one 5.** Swap that 5 for two 3s. The total rises from 5 to 6, so the amount goes up by exactly 1: now we are paying n + 1.
- **Case B: it uses no 5, so it is all 3s.** Then n is a multiple of 3. Since n is at least 8, n is at least 9, so there are at least three 3s (3 × 3 = 9). Swap three 3s (worth 9) for two 5s (worth 10). The amount goes up by exactly 1: now we are paying n + 1.

**Step 4: conclude.** In both cases n + 1 can be paid. *Why:* so the rule "if n works then n + 1 works" holds.

**Conclusion:** By induction every amount from 8 up can be paid. Examples: 9 = 3 + 3 + 3, 10 = 5 + 5, 11 = 3 + 3 + 5, 12 = 3 × 4, 13 = 3 + 5 + 5.

### Example 5: a "proof" where the step works but the claim is false

**Claim:** 2 + 4 + ... + 2n = n² + n + 1, for every n = 1, 2, 3, ... (Compare with Example 3: the correct total has no "+ 1".)

**Step 1: try the inductive step first.** Assume 2 + 4 + ... + 2k = k² + k + 1. Add the next term 2(k + 1): the sum is k² + k + 1 + 2k + 2 = k² + 3k + 3. The formula for k + 1 gives (k + 1)² + (k + 1) + 1 = k² + 2k + 1 + k + 1 + 1 = k² + 3k + 3. They match. So the step **works**. *Why:* this shows that dominoes would pass the fall along.

**Step 2: now check the base case.** For n = 1 the left side is 2, but the right side is 1 + 1 + 1 = 3. They do **not** match. *Why:* the first domino never fell.

**Conclusion:** The claim is false for every n (the true sum is always one less than the formula: n = 1 gives 2 vs 3, n = 2 gives 6 vs 7, n = 3 gives 12 vs 13). **Lesson:** the step alone proves nothing. Always check the base case.

## 2 real-life scenarios

*All numbers are illustrative (invented).*

### Scenario 1: seating for a training hall (commerce, HR)

An HR team sets up a training hall in a triangle shape: row 1 has 1 chair, row 2 has 2 chairs, row 3 has 3 chairs, and so on. They ask: "How many chairs for n rows?" By Example 1, the answer is n(n + 1) / 2. For 20 rows: 20 × 21 / 2 = **210 chairs**. Induction is what guarantees the formula is right for *any* number of rows. The base case is one row (1 chair). The step is: adding the next row of (k + 1) chairs to a hall that already has k(k + 1) / 2 chairs gives (k + 1)(k + 2) / 2 chairs.

### Scenario 2: a running balance in a data pipeline (data)

A small report starts the month with an opening balance of 1,000. Each day the net change is +50, and each day's closing balance becomes the next day's opening balance. The claim is: closing balance after day n = 1,000 + 50n.

- **Base case:** after day 1 the closing balance is 1,000 + 50 = 1,050. This equals the formula with n = 1.
- **Step:** if day k closes at 1,000 + 50k, then day k + 1 opens there, adds 50, and closes at 1,000 + 50k + 50 = 1,000 + 50(k + 1). This is the formula with n = k + 1.

So by induction day 30 closes at 1,000 + 50 × 30 = **2,500**, without calculating the 29 days before. This is also why, when you debug such a report, you check two things: "is the first day right?" and "does each day correctly use the previous day?".

## Practice questions

Answers are in `answer_key/Ch31_key.md`. Some questions ask only for the base case or the step; read each carefully.

**Q1** 🟢 A staircase has 40 steps. You know two facts: (A) you can stand on step 1; (B) if you can stand on any step, you can climb to the next one. State which fact is the base case and which is the inductive step. What can you conclude about step 40?

**Q2** 🟢 In the staircase of Q1, suppose fact (A) is removed (you are not sure you can stand on step 1) but (B) is kept. What can you conclude? Explain in one or two sentences.

**Q3** 🟢 Check (by calculating, not by proving) that 1 + 2 + ... + n = n(n + 1) / 2 for n = 1, 2, 3, 4 and 5 by filling in a small table with columns n, the sum added up by hand, and the formula's value. Then explain in one sentence why this table alone is not an induction proof.

**Q4** 🟡 Prove by induction that 1 + 4 + 7 + ... + (3n minus 2) = n(3n minus 1) / 2 for every n = 1, 2, 3, ... (the terms go up by 3 each time). Write the base case and the inductive step.

**Q5** 🟡 Handshakes: at a meeting of n people, everybody shakes hands once with everybody else. The number of handshakes is n(n minus 1) / 2. Prove it by induction for n = 1, 2, 3, ... (Hint: when the (k + 1)-th person arrives, how many new handshakes happen?)

**Q6** 🟡 A trainee saves 5 rupees in week 1, 10 in week 2, 15 in week 3, and so on (5 more each week). Prove by induction that the total saved after n weeks is 5n(n + 1) / 2. Then use it to find the total after 12 weeks.

**Q7** 🟡 Prove by induction that 2^n is bigger than n for every n = 1, 2, 3, ... (2^n means 2 multiplied by itself n times, so 2^3 = 8.) Hint for the step: 2^(k+1) = 2 × 2^k, and you may use that 2k is at least k + 1 when k is at least 1.

**Q8** 🔴 Prove by induction that 4^n minus 1 is a multiple of 3, for every n = 1, 2, 3, ... (Hint: 4^(k+1) minus 1 = 4 × (4^k minus 1) + 3. Check that this identity is correct, then use it.)

**Q9** 🔴 A shop only has 4-rupee and 7-rupee vouchers. (a) Find which amounts from 1 to 17 cannot be paid exactly. (b) Show that every amount from 18 upward can be paid exactly. (Hint: show the four amounts 18, 19, 20, 21 can be paid, then explain why each later amount can be reached by adding one 4-rupee voucher to an amount four steps earlier.)

**Q10** 🔴 Find the flaw. Someone "proves" that in any group of n employees, everyone has the same shoe size. Base case: a group of 1 employee, everyone trivially has the same size. Step: assume it holds for every group of k employees. Take a group of k + 1 employees. Remove one employee A: the remaining k have the same size by the assumption. Put A back and remove a different employee B: the remaining k have the same size again. The two groups of k overlap, so A, B and everyone else all share one size. So any group has one shoe size. Which line of the step fails, and for which value of k does it break?

## Mistake log

1. **Forgetting the base case.** Example 5 shows a step that works for a false claim. No first domino, no proof.
2. **Proving the step for one value only.** The step must work for a general k (a letter), not just k = 3.
3. **Using the claim you are trying to prove.** In the step, you may assume the claim for k, never for k + 1. Starting from k + 1 and "showing" 0 = 0 is circular.
4. **Algebra slips when tidying.** The proof is usually right in idea but the final match fails because of a sign or bracket; always write the target (the formula with k + 1) first and aim at it.
5. **Thinking a pattern for a few n is enough.** Five matching values (as in Q3) are evidence, not a proof.

## Recap

1. Induction proves a claim for every n from a start value using two parts: a base case and an inductive step.
2. The base case checks the first value by plain calculation: "the first domino falls".
3. The inductive step assumes the claim for k and shows it for k + 1: "each domino knocks over the next".
4. Both parts are needed; a step without a base case can "prove" false claims.
5. For sum patterns, write the sum to k + 1 as the sum to k plus the new term, use the assumption, then tidy to match the target.
