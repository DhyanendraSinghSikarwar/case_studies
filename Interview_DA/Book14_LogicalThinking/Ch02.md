## Concept in plain language

### What is a statement?

Logic works with **statements**. A statement is a sentence that makes a claim about how things are, and that claim can be settled as **either true or false, but not both**.

The value "true" or "false" is called the statement's **truth value**.

Think of it like a switch with two positions. A statement always has exactly one position, even if we cannot see which.

### The sorting rule

Ask: *"Can this sentence be called true or false?"*

| Kind of sentence | Example | Statement? |
|---|---|---|
| Fact claim, true | "Delhi is a city in India." | Yes, **true** |
| Fact claim, false | "A week has eight days." | Yes, **false** |
| Fact claim, answer unknown to us | "The first candidate Anita interviewed this year had a middle name." | Yes, truth value **unknown to us** |
| Question | "Is the invoice approved?" | No |
| Command or request | "Send the report by Friday." | No |
| Exclamation | "What a lovely result!" | No |
| Greeting, wish, blessing | "Good morning!" "Best of luck!" | No |
| Opinion or taste | "Chai is better than coffee." | No (no fact can settle it) |
| Open sentence (has a blank) | "x + 4 = 10" | No, until the blank is filled in |
| Self-contradicting loop | "This sentence is false." | No (it cannot be given a consistent value) |

### Three things that confuse beginners

1. **False is still a statement.** "A week has eight days" is a perfectly good statement. It just happens to be false. Being a statement is about *having* a truth value, not about being true.
2. **Unknown is still a statement.** If a fact exists but we cannot check it today, the sentence is still a statement. Only the *label* is "unknown to us".
3. **Opinions are not statements.** "This is the best phone" cannot be proved or disproved, because "best" depends on taste. But "This phone has a 5000 mAh battery" can be checked against the spec sheet, so it is a statement.

### Open sentences and context

An **open sentence** contains a blank that can change its truth, such as "x + 4 = 10" or "the salary is above 50,000". Until we say *which* x or *whose* salary, it is not true or false. Once the blank is filled ("when x = 6", "for Bilal"), it becomes a statement.

Many sentences also depend on **context** (place and time): "It is raining" is only a statement once we know where and when. In this book, if a question gives context (a table, a date), use it.

> **Why this matters for data work**
> A filter such as `salary > 50000` is an open sentence. When it is checked row by row, each row turns it into a statement that is TRUE or FALSE, and only the TRUE rows are kept. Knowing exactly what has a truth value is the base for all the logic in the next chapters.

## 5 solved examples

### Example 1: A plain true statement

> "The number 17 is greater than 12."

1. Is it a claim about how things are? Yes, about two numbers.
2. Can it be checked? Yes: 17 comes after 12.
3. **Result:** statement, **true**.
   *Why:* we decided "statement" first, and only then looked for the value.

### Example 2: A question

> "Is the invoice approved?"

1. Does it claim anything? No, it asks.
2. Can you answer "true" or "false" to the sentence itself? No. You answer "yes" or "no" to the *question*, which is a different thing.
3. **Result:** not a statement (question).

### Example 3: A command

> "Please send the report by Friday."

1. It tells someone to do something.
2. A request can be followed or ignored, but it is not true or false.
3. **Result:** not a statement (command).
   *Why:* only claims about the world can be true or false.

### Example 4: False and unknown, and an open sentence

(a) "A week has eight days."
(b) "The company had exactly 250 employees on 1 April 2015."
(c) "x + 4 = 10"

1. (a) is a claim and a week has seven days, so it is a **statement, false**.
   *Why:* false statements still count.
2. (b) is a claim about a past fact. A number really existed that day, so it is a **statement**. If nobody gives us the records, the truth value is **unknown to us**.
   *Why:* "not known by me" is different from "has no truth value".
3. (c) has a blank x. If x = 6 it is true, if x = 5 it is false. Without x it has no value: **not a statement (open sentence)**.

### Example 5: Opinion versus a measurable twin

(a) "This is the best phone on the market."
(b) "This phone has a 5000 mAh battery."

1. (a) What would decide "best"? Price, camera, battery, looks: different people weigh them differently. No fact settles it. **Not a statement (opinion).**
2. (b) You can open the spec sheet and check. So it is a **statement**; its value is whatever the sheet says.
3. **Trick to remember:** if you can say *what evidence would settle it*, it is probably a statement. If every person could honestly answer differently, it is an opinion.

## 2 real-life scenarios

### Scenario 1: Product page copy (commerce)

A shop's page for a water bottle (illustrative) says:

1. "Capacity: 750 ml." (the label on the bottle says 750 ml)
2. "Which colour would you like?"
3. "It is the most stylish bottle ever."
4. "Add to cart."
5. "The bottle is made of steel." (the spec sheet says plastic)

Sorting:

- 1: statement, true (matches the label).
- 2: not a statement (question).
- 3: not a statement (opinion).
- 4: not a statement (command).
- 5: statement, false (the sheet says plastic).

**Lesson:** only 1 and 5 can be fact-checked. A good analyst separates checkable claims from marketing talk.

### Scenario 2: Checking an employee table (HR and data)

Illustrative staff list:

| Employee | Department | Salary |
|---|---|---|
| Anita | HR | 42,000 |
| Bilal | Sales | 55,000 |
| Chitra | Sales | 48,000 |

Sentences:

1. "Bilal earns more than 50,000." Statement, **true**.
2. "Chitra works in HR." Statement, **false**.
3. "salary > 50,000" (no name). Open sentence, so **not a statement** yet. Applied to Anita it is false, to Bilal it is true, to Chitra it is false.
4. "Who earns the most?" Question, **not a statement**.

**Lesson:** that third sentence is exactly what a spreadsheet filter or SQL WHERE clause does. It tests every row and keeps those where it becomes true.

## Mistake log

1. **Thinking "false" means "not a statement".** False statements are still statements.
2. **Thinking "I don't know" means "not a statement".** A fact can exist even if you cannot check it.
3. **Treating opinions as facts.** Words like best, worst, nicer, tastiest signal taste.
4. **Treating open sentences as true or false.** "x + 4 = 10" and "salary > 50,000" need the blank filled first.
5. **Confusing a question with its answer.** The question has no truth value; only a sentence such as "Yes, it is approved" does.

## Recap

1. A statement is a sentence that is either true or false, never both.
2. Its truth value can be true, false, or unknown to us.
3. Questions, commands, exclamations, greetings and wishes are not statements.
4. Opinions are not statements; open sentences become statements once the blank is filled.
5. A spreadsheet or SQL filter is an open sentence tested on each row.
