## Concept in plain language

### Classification: putting things in boxes

**Classification** means sorting things into groups using a rule. A good rule is something you can check on each item: "is it a number or a word?", "is it paid every month?".

A good scheme of groups has two properties (consultants call this "MECE", which simply means):

- **No overlap:** each item fits exactly one group.
- **Nothing left out:** each item fits some group (a catch-all group such as "Other" helps, but if "Other" becomes the biggest group, the scheme is not doing its job).

### Odd one out

In an **odd one out** question you get a list (usually five) and one item does not follow the rule shared by the rest. Method:

1. Look at each item and write down its features (what it is, what it does, how many letters, which category, a number pattern).
2. Find a feature that **four share and one lacks**.
3. If more than one feature works, choose the **simplest, most natural** rule, and be ready to say why.
4. Say your rule in a sentence: "All except X are ___."

Typical rules:

| Type | Example rule |
|---|---|
| Category | all are drinks except one |
| Function | all write, one erases |
| Number property | all differ by +2, one differs by +3 |
| Letter position | letters jump by 2, one jumps by 3 |
| Count | all have 30 days, one has 31 |

### Analogies: "A is to B as C is to D"

An **analogy** says that the pair on the left has the same relationship as the pair on the right. Written: A : B :: C : D, read "A is to B as C is to D".

The method is the **make-a-sentence method**:

1. Find the relationship between A and B and say it as a sentence: "A pilot flies an aircraft."
2. Use exactly the same sentence for C and the options: "A driver drives a ___."
3. Check the **direction** (a part belongs to a whole, not the other way round).
4. If two options fit, make the sentence more specific.

Common relationship types:

| Relationship | Example |
|---|---|
| Part and whole | page : book |
| Tool and its use | knife : cut |
| Worker and place/tool | pilot : aircraft |
| Measure and quantity | kilogram : weight |
| Opposite | hot : cold |
| Degree (weak to strong) | drizzle : downpour |
| Cause and effect | spark : fire |
| Maker/producer and product | employee : payslip (a record of the work) |
| Letter or number rule | CAT : ECV (each letter moves forward 2) |

### Do not swap the order

"Doctor : Patient" is not the same as "Patient : Doctor". Always keep the left-right order the same on both sides.

---

> **Why this matters for data work**
> Analysts group things all day: expense heads, product categories, customer types, column types. A poor grouping scheme (overlapping groups, a giant "Other") leads to wrong totals. Spotting the odd one out is also the first step in finding errors and outliers in data.

## 5 solved examples

### Example 1: Odd one out by category

Find the odd one out: Tea, Coffee, Milk, Juice, Biscuit.

1. Features: tea, coffee, milk and juice can all be poured and drunk. A biscuit is solid and eaten.
2. Rule: "All except one are drinks."
3. Answer: **Biscuit.** Why: the rule splits 4 and 1, and it is the simplest rule.

### Example 2: Odd one out by letter jumps

Find the odd one out: ZX, WU, TR, QO, NK.

1. Write each letter's position in the alphabet: Z = 26, X = 24; W = 23, U = 21; T = 20, R = 18; Q = 17, O = 15; N = 14, K = 11.
2. Gap from first to second letter: 26 to 24 is -2; 23 to 21 is -2; 20 to 18 is -2; 17 to 15 is -2; 14 to 11 is -3.
3. Rule: "The second letter is 2 steps before the first." Answer: **NK** (it jumps 3). Why: the numbers show it, not just a feeling.

### Example 3: Analogy (tool and use)

Knife : Cut :: Pen : ? Options: Ink, Write, Paper, Desk.

1. Sentence for the first pair: "A knife is used to cut."
2. Same sentence: "A pen is used to ___." Only **Write** completes the sentence.
3. Why not Ink or Paper? They are things a pen uses or touches, not what a pen is used to do. The relationship (tool to its job) must stay the same.

### Example 4: Analogy, watch the direction

Doctor : Patient :: Teacher : ? Options: School, Student, Book, Exam.

1. Sentence: "A doctor treats a patient." (a worker, and the person served)
2. Same sentence: "A teacher teaches a ___." Answer: **Student.**
3. School is the trap: "doctor" would pair with "hospital" for a place, which is a different relationship. Keep the same relationship: worker and the person served.

### Example 5: Classification with a rule (illustrative)

A small warehouse has these expenses: Warehouse rent, Packing tape, Delivery fuel, Security guard salary, Card payment fees. Sort them into **fixed** (the amount does not change with how many orders go out) and **variable** (the amount grows with orders).

1. Warehouse rent: the same every month, so fixed.
2. Packing tape: more orders, more tape, so variable.
3. Delivery fuel: more deliveries, more fuel, so variable.
4. Security guard salary: same each month, so fixed.
5. Card payment fees: a percentage of each sale, so variable.
6. Result: fixed = 2 (rent, guard salary); variable = 3 (tape, fuel, card fees). Check: 2 + 3 = 5 items, none left out and none in both.

## 2 real-life scenarios

### Scenario 1 (commerce): sorting a product catalogue (illustrative)

A shop has 10 products: phone, phone cover, charger, notebook, pen, backpack, earphones, stapler, tablet, folder. The owner wants two top groups: "Electronics" and "Stationery and bags".

- Electronics: phone, charger, earphones, tablet (4). Phone cover is an accessory, so the owner must decide where it goes. If the rule is "needs electricity or contains electronics", the cover goes in the second group.
- Stationery and bags: notebook, pen, backpack, stapler, folder, phone cover (6).
- Lesson: borderline items must be settled by a written rule. Otherwise two staff members will file the same item in two places and totals will differ.

### Scenario 2 (data): a ledger with a giant "Other" (illustrative)

A ledger has 40 lines. Staff used the group "Misc" for 22 of them. That means more than half the data has no meaningful label, so a report by group says very little.

- Fix: split "Misc" into groups using a rule (for example: Travel, Food, Software, Office supplies) and keep "Other" for rare cases only.
- Test the new scheme: pick any line, and ask "does it fit exactly one group?". If two staff would choose differently, the rule needs another sentence.

## Mistake log

1. **Choosing a rule that fits "my favourite" item, not four of them.** A correct rule must separate four items from one; check all five.
2. **Reversing the order in an analogy.** "Part : whole" is not the same as "whole : part"; test the same sentence in both pairs.
3. **Picking an option that is only loosely linked.** An option related to the words is not the same as one with the same relationship. Use the full sentence.
4. **Letting categories overlap.** If two people can file the same item in two groups, add a clear tie-break rule.
5. **Counting by feel instead of writing features down.** For letters and numbers, write the positions or differences; the pattern is then visible.

## Recap (5 lines)

1. Classification sorts items into groups by a rule you can check on each item.
2. A good scheme has no overlap and leaves nothing out; a huge "Other" is a warning sign.
3. Odd one out: list features, find the rule that four share and one breaks, and state it in a sentence.
4. Analogy: write the A-to-B relationship as a sentence and reuse it exactly for C and D, with the order unchanged.
5. If two answers seem possible, pick the simplest relationship, or say the question is ambiguous and name what would settle it.
