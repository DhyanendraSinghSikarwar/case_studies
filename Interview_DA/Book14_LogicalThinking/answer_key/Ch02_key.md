# Chapter 2 Answer Key

## Self-check answers

1. **No.** It is a command. Commands are carried out or ignored; they are not true or false.
2. **Yes.** It is a claim about a fact in the past; the truth value exists, we just do not know it. Label: statement, unknown to us.
3. **No.** It is an open sentence. It is true when x = 6 and false for other values; without x it has no truth value.

---

## Practice answers

Step used for every item: (1) does it claim something about how things are? (2) if yes, what would settle it? (3) label.

### Easy

| Q | Label | Reasoning |
|---|---|---|
| Q1 | **True** | A claim about numbers. 12 + 9 = 21. |
| Q2 | **Not a statement** (command) | "Please switch off" tells someone to act. |
| Q3 | **True** | Mumbai is a city in India. |
| Q4 | **Not a statement** (question) | It asks; yes or no is not applicable. |
| Q5 | **False** | A year has 12 months. Still a statement. |
| Q6 | **Not a statement** (exclamation) | It expresses feeling and claims nothing checkable. |
| Q7 | **True** | By definition, a triangle has three sides. |
| Q8 | **False** | 15 divided by 2 leaves remainder 1, so it is odd. |
| Q9 | **Not a statement** (greeting) | A greeting is not a claim. |
| Q10 | **False** | 7 is greater than 5. |

### Medium

| Q | Label | Reasoning |
|---|---|---|
| Q11 | **Not a statement** (opinion) | "Better" depends on taste; no evidence settles it. |
| Q12 | **Not a statement** (open sentence) | True if n = 7, false otherwise; n is not given. |
| Q13 | **Not a statement** (wish or blessing) | It expresses a hope, not a claim. |
| Q14 | **False** | 8 + 7 = 15, not 14. |
| Q15 | **True** | A square has four right angles, so it is a rectangle (with extra equal sides). |
| Q16 | **Not a statement** (question) | It asks. (The answer, "29 is prime", would be a true statement, but that is another sentence.) |
| Q17 | **True** | A compound statement; every whole number is even or odd, and 6 is even. At least one part is true, so the whole "either...or" is true. |
| Q18 | **Not a statement** (command) | An instruction. |
| Q19 | **True** | January, March, May, July, August, October and December have 31 days. |
| Q20 | **Not a statement** (opinion) | "Best way" is a judgement; people can honestly disagree. |

### Hard

| Q | Label | Reasoning |
|---|---|---|
| Q21 | **True** | Both parts must hold: Bilal is in Sales (table) and 55,000 > 50,000. |
| Q22 | **False** | Anita earns 42,000; Chitra earns 48,000. 42,000 is not more than 48,000. |
| Q23 | **Not a statement** (open sentence) | "The salary" does not say whose. True for Bilal and Dev, false for Anita and Chitra, so no single value. |
| Q24 | **True** | "Either...or" is true when at least one part is true; Dev is in IT. |
| Q25 | **True** | The table has four rows: Anita, Bilal, Chitra, Dev. |
| Q26 | **False** | Sales employees are Bilal (55,000) and Chitra (48,000). 55,000 + 48,000 = 103,000, not 100,000. |
| Q27 | **Not a statement** (question) | It asks; the answer "Dev" would be a statement. |
| Q28 | **True** | Count: This (1) sentence (2) has (3) five (4) words (5). It talks about itself, but the claim is checkable and correct. |
| Q29 | **Statement but unknown to us** | A definite fact about a real event (the candidate either had a middle name or not), but no information is given. |
| Q30 | **Not a statement** (self-contradicting loop) | If it were true, then what it says (it is false) would hold, so it is false. If it were false, then it would be telling the truth. It cannot be given a consistent value, so we do not count it as a statement. |
