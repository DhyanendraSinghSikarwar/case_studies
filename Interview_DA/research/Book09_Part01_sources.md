## Star-assignment reasoning (judgement, not measured)
No source gives frequencies. 3 stars: definitions every ML-touching interview opens with (what ML is, supervised vs unsupervised, features/label, classification vs regression, ML vs rules, when to use ML, AI vs ML vs DL, project workflow, "can we use AI to predict X"), because every question bank found starts here. 2 stars: applied and practical items (inline-data tasks, sklearn code reading, algorithm families, domain uses in HR/e-commerce/finance, bias, privacy, interpretability, imbalance, project pitch). 1 star: emerging or differentiator topics (reinforcement learning, PCA, generative vs predictive, drift, vendor evaluation, responsible workflow design). Because ML is rare for 0-3 year analyst roles, no question is above its source evidence.
