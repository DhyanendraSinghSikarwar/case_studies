## Star reasoning
- Rating logic: ⭐⭐⭐ = appears in nearly every prep list read (WSCubeTech, Keka, Chandoo, Spreadsheeto, Jaro) and the basics are the opening of any Power BI round (components, Desktop vs Service, building blocks, report vs dashboard, workflow, Power Query/DAX roles, .pbix, Import vs DirectQuery). Power BI is common (about one-third of JDs) but not universal, so only the opening basics get three stars.
- ⭐⭐ = listed in some sources or directly implied by Microsoft docs and likely live-interview follow-ups (licence types, Mac limitation, live connection, Fabric, Report Server, moved-file connection error, publishing, co-authoring).
- ⭐ = differentiators and edge items (.pbit/.pbip, privacy levels, composite models, Report Builder, dataflows, external tools, VertiPaq, Embedded, Direct Lake, shared-model design, 200-viewer sharing).
- Difficulty: 🟢 definitions, 🟡 comparisons and troubleshooting, 🔴 architecture/licensing-design judgement.
