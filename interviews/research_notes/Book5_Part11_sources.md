Findings from the runs: a memoised LCS on two disjoint strings of length n raises RecursionError from n = 520 (400 and 480 pass; observation at default limit 1000); memoised edit distance, ASCII delete and LCS at 1000 x 1000, LPS at 2000 letters, regex at 1000 letters vs `a*` x 500 all raise RecursionError; the grid cache recursion is 1199 deep at 600 x 600 (fails) and 799 deep at 400 x 400 (works); a winding corridor of 61 x 61 (1921-cell path) breaks a memoised longest-increasing-path DFS (a full boustrophedon snake did NOT, because DFS order took a short chain; the corridor design with zero-valued walls was needed and the first 'm*n deep' wording in the prompt was corrected); a wall cell of value 0 beside the start adds one cell to the path length (L + 1). Greedy minimum path sum is wrong on 98 of 500 random grids; a max-sum path needs more dungeon health than the optimum on 5 of 500; a prefix back-pointer minimum path differs from the suffix tie rule on 244 of 500; the classic back-pointer LCS differs from the lexicographically smallest LCS on 39 of 500. Exhaustive: all 961 string pairs of length <= 4 over {a, b} for LCS recovery, SCS, edit script, longest common substring and ASCII delete; all binary strings of length <= 8 for LPS, palindromic substring count and cuts; 1241 small grids for the path tie rule and count; all 243 matrix chains of 4 matrices with dimensions 1..3; all 512 0/1 3 x 3 assignment matrices.
