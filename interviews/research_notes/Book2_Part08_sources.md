## AI-era notes
- Agent loops are now a standard interview topic with a recurring design prompt (an agent stuck in a loop on a failing tool; a customer-service agent with guardrails, cost controls and failure recovery) and depth questions on planning, memory, MCP and multi-agent trade-offs.
- The common failure of weak answers is reaching for agents or multi-agent systems when a workflow would do; both Anthropic posts stress starting simple and paying attention to token cost.
- Reviewing LLM-written agent loops is a plausible AI-era round (Q44).
