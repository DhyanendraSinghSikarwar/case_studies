## AI-era notes
- Advanced RAG is now judged by trade-off reasoning: which stage fixes which measured failure, and what each adds in latency and cost (routing so that expensive techniques only run when needed).
- Reviewing LLM-written hybrid-plus-rerank code is a plausible AI-era round (Q42).
- Agentic RAG interviews focus on when not to use an agent loop and how to bound it.
