## AI-era changes noted
- Interviewers increasingly ask candidates to critique LLM-generated statistical analysis (wrong independence assumption, VIF threshold misquoted, frequentist wording for a credible interval); added a Q on LLM benchmark comparison with credible intervals and on reviewing LLM analysis.
- Puzzle answers are expected with a quick NumPy/scipy simulation as verification; "simulate it" follow-ups are common, so many questions will carry Monte Carlo code.
- Quant prep sites report interviewers deliberately perturb classic problems (biased coin, n-sided die, asymmetric payoff), so answers must teach technique (conditioning, recursion, linearity) rather than memorised results.
- Some source facts to correct in answers: one scraped page defined an improper prior wrongly (improper = does not integrate to 1); VIF cutoffs (5 vs 10) are convention; some CUPED % claims are unsourced.
